Open the generator for Amazon
Step by step
01
Open Login & security
Sign in at amazon.com, hover over “Account & Lists” → “Account” → “Login & security”. The direct shortcut is amazon.com/a/security.
02
Open Two-Step Verification settings
Next to “Two-Step Verification (2SV)”, click “Edit” or “Manage”, then choose the authenticator-app option (“Authenticator App” / “Add new app”).
03
Reveal the key
Amazon shows a QR code. Look for a manual-entry link — often “Can’t scan the barcode?” — to display the alphanumeric setup key. Copy it, or screenshot the QR and paste the image into the generator.
04
Generate the first code
Paste the key into 2facounter.com. A live 6-digit code appears and refreshes every 30 seconds; the calculation runs entirely in your browser.
05
Confirm the code with Amazon
Enter the current code in Amazon’s verification box and save. Amazon marks the authenticator as an active 2SV method.
06
Save the backup route
Store the Base32 key and any backup codes in your encrypted vault. If Amazon shows a “primary method” choice, keep the authenticator first and treat SMS as a fallback you control.
Amazon account details
Amazon retail and AWS are separate accounts
Two-Step Verification on amazon.com protects shopping, Prime, Kindle and the retail account. AWS uses its own IAM users and root account with a separate MFA setup — enabling one does not enable the other. If you are here for AWS, use the dedicated AWS IAM guide instead; the keys and consoles are unrelated.
The authenticator option is easy to miss
Amazon may steer accounts toward SMS or voice call, and the authenticator choice can sit behind “Add new app” or “More options”. Look for “Authenticator App” rather than “Phone number”. Once enrolled, you can remove the phone method if you prefer not to keep a SIM-swap lane open — but consider keeping a recovery phone number that is not your main SIM.
What is verified here, and what is not
The TOTP mechanics are standards, not opinions: Amazon’s authenticator option issues a Base32 key that any RFC 6238 implementation turns into the same 6-digit code, and that is what this page depends on. The screen labels — “Authenticator App”, “Add new app”, “Can’t scan the barcode?” — could not be checked against Amazon’s own help centre, which blocks automated access and renders article bodies client-side. They are written to describe the control rather than to quote one build. If your screen words it differently, the control described is still the one to look for.
TV devices and household sharing
Fire TV, Kindle and other signed-in devices may keep their sessions, but some will ask for the code again after a security change. If a household member uses the account, make sure they can reach you for a code or have their own profile — and never share the Base32 key itself.

Back in Security → “Anti Phishing Code”: Binance then stamps every real email with a code of your choosing, so fake “account alert” mail becomes instantly recognizable. In the same settings, add the withdrawal addresses you actually use — new whitelist entries face a withdrawal pause before they become usable, which is what stops a thief from redirecting your funds on day one.
07
Save Binance’s recovery key offline
However Binance’s flow surfaces recovery material to you, write it down — it’s your path back if every device with the secret dies.
What is verified here, and what is not
The mechanics are standards; the screens are not
The authenticator method is standard RFC 6238 TOTP — 6 digits, 30-second period, SHA-1 — which is why any authenticator, including a browser-based one, produces codes Binance accepts. That part rests on the standard rather than on Binance’s help centre. The on-screen path in the steps does not: Binance’s support centre renders its articles client-side and does not expose them to automated reads, so the labels are written to describe the control rather than to quote one build. If your account shows different wording, the control described is still the one to look for.
The cooldown after a 2FA change is real, and it is the point
Binance suspends withdrawals and P2P transfers after an authenticator change while the change settles. That hold is a feature: it is the window in which the real owner can react to an attacker who has just re-enrolled the factor. Treat any such hold as expected rather than as evidence of compromise — and keep the setup key backed up so you never have to trigger it casually.

Why the authenticator option is worth the extra minute
SMS is the weak factor, not the convenient one
A code delivered by text message proves control of a phone number, not of a device. Numbers get ported, recycled and social-engineered at the carrier, and the account holder usually learns about it after the fact. An authenticator code proves possession of the key itself, which nobody can transfer out from under you.
TikTok accounts are traded, which changes the threat
A password leak is an annoyance; a TikTok account with an audience is inventory. That is why takeover attempts on social accounts tend to be patient and social — a fake login page, a “verification” DM, a support impersonator. None of those need to break encryption. They need you to type a code into the wrong place, so check the address bar and never relay a code to someone who asks for it, including someone claiming to be TikTok staff.

The TOTP mechanics are standards, not opinions: TikTok’s authenticator method issues a Base32 key that any RFC 6238 implementation turns into the same 6-digit code, and that is what this page depends on. The navigation path in the steps — Settings and privacy → Security → 2-step verification → authenticator — mirrors TikTok’s own help-centre topic. The exact button and link wording does not: TikTok reworks its settings screens between app versions and regions, and the labels quoted here accommodate that variation rather than certify a single build. If your screen words a control differently, the control described is still the one to look for.

Twitch details that trip people up
The phone number is a Twitch gate, not the second factor
Twitch uses a verified phone number as an eligibility check before enabling 2FA, and it uses SMS as the recovery path. The authenticator app is a separate method you select afterwards. If you do not want SMS codes in daily use, keep the number for recovery only and make the authenticator your primary method — but do not remove it, because Twitch has no static backup codes.
Your stream key deserves its own protection
The stream key is a credential that lets software broadcast as your channel. It is stored in OBS or your encoder, not in the authenticator. If you suspect a leak, reset the stream key in the Twitch dashboard immediately — 2FA protects account login, not an already-copied key.
2FA is tied to account features and monetization
Twitch uses 2FA as a requirement for some account actions and creator features, and the exact list changes over time. If a payout, raid, or chat feature asks for 2FA, enabling an authenticator satisfies it. Check the current security page rather than relying on old guides.

Zoom account details
Account-level 2FA versus per-meeting security
Zoom’s two-factor authentication protects sign-in to your Zoom account. Meeting passwords, waiting rooms, and passcodes protect individual meetings. They are separate layers: enabling 2FA does not remove the need for a meeting passcode, and a strong meeting policy does not protect your account.
Admins can enforce 2FA or route sign-in through SSO
On a work or school account, an admin may require 2FA for all users or enforce SSO through an identity provider. If the authenticator option is missing, that is an account policy. Ask your admin which method is allowed; do not try to bypass enforced SSO.
Cloud recordings and connected apps stay sensitive
Signing in with 2FA does not encrypt cloud recordings or revoke access granted to connected apps. After enabling it, review “Apps” and “Recordings” in the Zoom web portal, remove integrations you no longer use, and confirm who can view recorded meetings.
